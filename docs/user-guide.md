## 一、这是什么

S3 Client 是一个**自托管的 S3 兼容对象存储控制台**：你在浏览器（或桌面应用）里管理自己的桶与对象，服务端只负责保存账号配置、代理请求与生成签名，**对象数据始终在你的 S3 服务上**。

| 形态 | 打开方式 | 说明 |
|---|---|---|
| Web 端 | 浏览器访问后端地址（默认 `http://127.0.0.1:8080`，与后端同源） | 前后端全 HTTP 通信，无需额外插件 |
| 桌面端 | 安装 Tauri 2 打包的 `.exe` / `.deb` / `.dmg` 后启动 | 与 Web 端是**同一套前端**，不使用 Tauri IPC，全部走 HTTP（见 [十、桌面端](#十桌面端)） |

### 典型使用场景

1. 用一组 AccessKey 快速浏览 / 检索桶内对象，替代各厂商网页控制台。
2. 把本地文件上传到任意 S3 兼容存储（浏览器直传，不经过本服务中转数据）。
3. 跨桶、跨账号搬迁数据，或做增量同步。
4. 处理版本控制桶的历史版本与误删对象（回收站还原）。
5. 兜底配置桶级能力：版本控制、生命周期、加密、CORS、静态网站、桶策略、桶标签。

### 前置条件

1. **一个 S3 兼容服务**：MinIO、RustFS、阿里云 OSS、腾讯云 COS、AWS S3 等均可。
2. **一组可用凭据**：AccessKey ID + AccessKey Secret，且该账号至少有对应桶的读写权限。
3. **可访问的 Endpoint**（形如 `oss-cn-hangzhou.aliyuncs.com`、`127.0.0.1:9000`）。
4. 若由他人部署本服务：拿到**后端地址**；后端启用了鉴权时还需要 **Token**（环境变量 `S3C_TOKEN`）。

### 界面总览

| 区域 | 内容 |
|---|---|
| 顶栏左侧 | 产品名 `S3 Client`；桌面端额外显示 `Desktop` 标记 |
| 顶栏右侧 | 语言按钮（`中文` / `EN`，点击切换）、主题按钮（`跟随系统` / `浅色` / `深色`，点击循环切换）、连接状态（`已连接` / `连接异常`） |
| 左侧导航「数据操作」 | 对象管理、桶管理、回收站、文件上传、文件迁移 |
| 左侧导航「配置」 | 账号管理、服务器设置 |

> 后端不可用时会显示红色横幅「无法连接后端：…」与「去配置」按钮；此后每 5 秒探测一次 `/api/health`，后端恢复后自动重新加载账号并清除错误，无需手动刷新。

> 每个菜单对应一个 URL hash（如 `#/objects`、`#/buckets`），可直接收藏 / 分享到某个菜单。

## 二、首次使用

按下面 5 步走完，即可开始管理对象。

### 第 1 步：确认后端连接（服务器设置）

1. 打开左侧「配置」→**服务器设置**。
2. 检查「后端地址」：留空表示**同源**（浏览器打开地址即后端地址）；桌面端默认是 `http://127.0.0.1:8080`。
3. 若后端配置了 `S3C_TOKEN`，在「鉴权 Token」中填入同样的字符串；可留空。
4. 需要跨会话保留 Token 时勾选「跨会话保留 Token（localStorage，仅本机可信环境使用）」；不勾选则仅存于 sessionStorage，**关闭标签页即失效**。
5. 点「全部检测」可一次探测所有已配置的服务端，正常时还会显示后端版本号。

### 第 2 步：新增账号

1. 打开「账号管理」→ 右上角「+ 新增登录」。
2. 先在**服务商按钮区**选择服务商（按分组排列，点一下即自动填好 Path-style / HTTPS / 区域 / Endpoint 的推荐值）：

| 分组 | 服务商（按钮文案） |
|---|---|
| 兼容 | `S3 兼容`（MinIO / 私有云 / 其他自定义 Endpoint）、`RustFS`（本地验证 S3：`127.0.0.1:9000`） |
| 国内 | `阿里云 OSS`、`腾讯云 COS`、`华为云 OBS`、`火山引擎 TOS`、`百度智能云 BOS`、`京东云 OSS`、`七牛云 Kodo` |
| 国外 | `AWS S3`、`Cloudflare R2`、`Wasabi`、`Backblaze B2`、`DigitalOcean Spaces`、`Linode / Akamai`、`Scaleway`、`Hetzner` |

3. 填写表单（字段含义见下表）。
4. 需要时点「拉取列表」拉取该账号的桶 —— 新建账号时用临时凭据试探（**不落库**），编辑已有账号时用已保存配置拉取；拉取前必须已填 Endpoint / AccessKey / SecretKey。
5. 点「保存并登录」（新建）或「保存」（编辑）。新建成功后会自动切换到该账号。

| 字段 | 说明 |
|---|---|
| 名称 | 显示名，例如「生产环境 MinIO」 |
| 区域 Region | 可从候选列表选择，也可手动输入；**选择区域会自动填充 Endpoint** |
| Endpoint | 服务地址，例如 `cos.ap-guangzhou.myqcloud.com` 或 `127.0.0.1:9000` |
| 公网 Endpoint | 浏览器直传 / 公开链接可达的地址，留空与 Endpoint 相同 |
| 默认 Bucket | 该账号的默认桶（进入对象管理时会自动进入）；可下拉选择、手动输入或用「拉取列表」获取 |
| AccessKey ID / AccessKey Secret | S3 凭据；编辑账号时 Secret **留空表示保持不变** |
| Path-style | MinIO / 私有云常需勾选（形如 `http://host/bucket/key`） |
| 使用 HTTPS/TLS | 是否用 TLS 连接 |

### 第 3 步：连通性测试

1. 在账号列表的「连通性」列点「测试」。
2. 状态会依次显示 `测试中…` → `正常` 或 `失败`；失败时把鼠标悬停在 `失败` 上可看到具体原因。
3. 常见原因见 [十三、排障](#十三排障)。

### 第 4 步：看到桶

进入「对象管理」后的第一屏是 **Bucket 列表页**（标题「Bucket 列表」，显示「共 N 个」）：

- 每行有「生命周期」「进入」「删除」三个按钮；
- 「进入」= 进入该桶浏览对象；
- 桶也可以从「桶管理」菜单查看：每行是「管理」「删除」。

### 第 5 步：创建桶

1. 在 Bucket 列表页点「+ 创建 Bucket」（或在「桶管理」点「+ 新建桶」）。
2. 在「创建桶」对话框中填写：
   - **名称**：3-63 位小写字母 / 数字 / 连字符；
   - **读写权限**：`私有（推荐）` / `公共读` / `公共读写（不推荐）`。
3. 点「创建」。成功后提示「已创建桶「名称」」并直接进入该桶。

> 删除桶时要求**桶必须为空**，否则服务端拒绝（提示 `bucket not empty`）。

## 三、浏览对象

进入「对象管理」并选中某个桶后，页面自上而下是：**位置栏 → 操作栏 → 统计条 → 上传队列（有任务时）→ 快捷键提示条 → 错误横幅（出错时）→ 对象列表 → 分页按钮**。

### 目录浏览：前缀与分隔符

- 服务端按「前缀（prefix）+ 分隔符（`/`）」列举：**当前前缀下的文件**和**以 `/` 结尾的公共前缀（文件夹）**分别返回，界面上文件夹在前、文件在后。
- 单击文件夹行（或点文件夹名）进入该目录；面包屑显示「桶名 / 目录 / 子目录」，点任意一级可跳回。

### 路径编辑

1. 点面包屑右侧的 **✎** 按钮（悬停提示「编辑路径直接跳转」）进入编辑态。
2. 输入完整路径，例如 `dir/sub/`（不写结尾 `/` 会自动补上）。
3. **Enter** 提交跳转，**Esc** 取消；输入框失去焦点（blur）也会提交。

### 本地过滤

- 位置栏右侧的过滤框（占位提示「过滤当前目录…」）对**已加载的条目**做本地关键字过滤，不会重新请求服务端。
- 过滤生效时显示 `命中数/总数` 徽标与「清除」按钮；无匹配时列表提示「没有匹配「关键字」的对象」。

### 排序

| 操作 | 结果 |
|---|---|
| 点击列头「名称」/「大小」/「修改时间」 | 切换排序列；再次点击同一列切换升序（▲）/ 降序（▼） |
| 文件夹 | **恒在前**，且始终按名称排序（不随排序列变化） |
| 文件 | 按所选列排序；名称使用数字友好的本地化比较（`a2` 排在 `a10` 之前） |

> 排序与过滤都只作用于**已加载**的条目（见下方分页）。

### 分页：加载更多 / 加载全部

| 按钮 | 行为 |
|---|---|
| 「加载更多」 | 追加下一页（每次请求 100 条，与服务端 `maxKeys` 上限 1000 不冲突） |
| 「加载全部」 | 连续翻页直到末尾；**最多 200 页（约 2 万条）**，达到上限会提示「对象较多，仅加载前 N 条」 |
| 按钮右侧徽标 | `还有更多`（服务端仍被截断）/ `已到末尾`（已取完） |

加载全部完成后会提示「已加载全部 X 个文件 / Y 个文件夹」。

### 虚拟滚动与大列表

| 视图 | 渲染策略 |
|---|---|
| 列表视图（默认） | 窗口化渲染：只渲染可视区 + 上下各 12 行缓冲，行高 42px，滚动容器最高约 640px（`min(60vh, 640px)`） |
| 网格视图 | 卡片式网格，**最多渲染前 300 项**，超出时提示「网格视图仅显示前 N 项（共 M 项），切换列表视图可浏览全部」 |

用统计条右侧的「📊 网格视图」/「📊 列表视图」按钮切换视图。

### 选择条目

| 操作 | 结果 |
|---|---|
| 单击文件行 | 切换该文件选中状态 |
| 单击文件夹行 | 进入该目录 |
| 勾选行首复选框 + **按住 Shift 点击**另一个复选框 | 在两次点击之间做**范围选择** |
| 「全选」复选框 | 选中 / 取消选中当前目录已加载的全部文件（等价于 **Ctrl/Cmd+A**） |

统计条会显示「📊 N 个文件 · 共 大小」与「已选 N 个 · 大小」。

### 工具栏按钮

| 按钮 | 作用 |
|---|---|
| 刷新 | 重新拉取桶列表与当前目录（重置分页、选择与滚动位置） |
| ↑ 上级 | 回到上一级目录（根目录时禁用） |
| ← 返回桶列表 | 回到 Bucket 列表页 |
| 上传文件 | 选择文件上传到**当前目录**（见 [四、上传](#四上传)） |
| + 新建文件夹 | 新建前缀（S3 无真实目录，服务端写入一个以 `/` 结尾的空对象） |
| 复制到… / 移动到… | 对选中文件打开「复制/移动到…」对话框 |
| 复制链接 | 为选中文件批量生成 **1 小时**签名链接并复制（每行一个） |
| ZIP 下载 | 把选中文件流式打包为 ZIP 下载 |
| 批量改元数据 | 对选中对象统一修改 ACL / 标签 / 存储类型 |
| 删除 | 删除选中文件（弹确认） |

### 行内操作与右键菜单

- 每个文件行末尾有「下载」「预览」「⋯」三个按钮；文件夹行只有「⋯」。窄屏下按钮常显。
- 右键任意行（或点「⋯」）打开菜单：

| 条目（文件夹） | 条目（文件） |
|---|---|
| 打开文件夹 | 下载 |
| 复制路径 | 预览 |
| 复制到… | 复制签名链接（1 小时） |
| 移动到… | 复制 Key |
| 删除文件夹（含全部内容） | 复制到… / 移动到… / 重命名 / 详情 / 权限设置 / 编辑标签 / 版本 / 删除 |

- 菜单支持键盘操作：**↑ / ↓** 在条目间循环，**Home / End** 跳到首尾，**Esc** 关闭。
- 「详情」打开「对象详情」弹窗：Key、大小、修改时间、Content-Type、ETag、存储类型、元数据，并提供「切换」（存储类型）、「编辑 HTTP 头」、「权限设置」、「编辑标签」、「版本」入口。

## 四、上传

有**两个入口**，共用同一套上传队列（并发控制、状态机、取消逻辑一致）：

1. 「文件上传」菜单（独立页面，可先设统一前缀再批量上传）；
2. 「对象管理」工具栏的「上传文件」（上传到**当前目录**）。

### 入口一：文件上传菜单

1. 在「文件前缀」中填写前缀，例如 `dir/sub`（不填则上传到桶根目录）。key 拼接规则：`前缀（去掉结尾的 /）+ "/" + 文件名`。
2. 点击虚线框选择文件，或把文件**拖拽**到框内（支持多选；如果选错可再次选择，同一文件不会被拒绝）。
3. 点「开始上传」。
4. 观察进度：顶部总进度条 + `已完成数/总数 · 百分比`，每条显示 key、大小与状态。

| 按钮 | 行为 |
|---|---|
| 开始上传 | 上传当前列表中所有**未完成且未取消**的条目 |
| 重试失败 | 把状态为「失败」的条目重置为「等待」并立刻重跑 |
| 清除已完成 | 只移除「完成」条目，保留等待 / 失败项便于重试 |
| 清空 | 中止在途上传并清空整个列表 |
| 条目上的 ✕ | 移除该条目；在途条目中止后回到「等待」（可再次上传） |
| 「完成」条目上的「复制链接」 | 生成 1 小时签名 GET 链接并复制，提示「已复制下载链接（1 小时有效）」 |

| 状态 | 含义 |
|---|---|
| 等待 | 已入队，尚未开始 |
| 签名中… | 正在向服务端申请签名 URL |
| 百分比 | 正在直传（浏览器 → S3） |
| 完成 | 上传成功 |
| 失败 | 失败，可「重试失败」 |

全部完成时提示「已上传 N 个文件」或「上传完成 ok 个，失败 fail 个」，并带「查看对象」按钮可直接跳到对象管理。

### 入口二：对象管理内上传

1. 进入目标目录，点「上传文件」选择文件（按钮在传输期间显示「上传中…」并禁用）。
2. 列表上方出现上传队列条：总进度、`完成数/总数 · 百分比`、每个条目的 key 与状态（`已取消` / 失败原因 / 百分比 / ✓），以及 ✕ 取消按钮（对「等待 / 上传中」条目可见）。
3. 完成后提示「已上传 N 个文件到当前目录」（有失败则「上传完成 ok 个，失败 fail 个」）并自动刷新当前目录。

> 「对象管理」里的队列是「边传边加」的：上传过程中继续选择文件会追加到本轮。

### 并发与分段规则

| 条件 | 行为 |
|---|---|
| 文件 **< 100MB** | 单次 PUT：服务端生成 v4 签名 PUT URL，浏览器直接上传到 S3（不经过本服务） |
| 文件 **≥ 100MB** | 自动分段上传：每段 **10MB**、**4 路并发**，依次 `init → 逐段 PUT → complete` |
| 分段并发 | 单文件最多 4 个分段同时上传（段数不足 4 时按实际段数） |
| 分段重试 | 单段失败按退避重试（约 0.5s → 1.5s → 3.5s，最多 4 次尝试）；网络错误、非 2xx 都会重试 |
| 任一段最终失败 | 立即 `abort` 清理该次分段会话，避免残留分片 |
| 取消上传 | 中止浏览器侧请求，并尽力 abort 分段会话 |
| 整体并发 | 队列层面同时最多 **2 个文件**（每段预签名有效期 1 小时） |

> 分段上传要求桶的 CORS **暴露 `ETag` 响应头**：否则会出现「分段上传完成但未读取到 ETag，请确认 Bucket CORS 暴露 ETag 响应头」。相关失败提示还有「分段上传失败：HTTP 状态码」「分段上传网络错误」。

> 单次 PUT 有 5GB 上限（服务端约束）；超过请使用分段上传（≥100MB 自动切换）。

### 增加文件前缀

上传与迁移都支持追加前缀：上传用「文件前缀」输入框，迁移用「目标前缀（增加前缀）」。前缀不会改动原文件名，只前置到目标 key 上。

## 五、下载与预览

### 下载（保存为文件）

点行内「下载」或右键「下载」，文件名取 key 的最后一段。

- 下载**经服务端代理**转发，并强制以附件形式保存（`Content-Disposition: attachment`），内容不会进入浏览器的渲染管道；
- 请求携带鉴权头，因此在启用 `S3C_TOKEN` 的部署下同样可用；
- 失败只提示（例如「下载「key」失败：…」），不会把错误响应当成文件保存下来。

### 分享：1 小时签名链接

| 入口 | 行为 |
|---|---|
| 右键 →「复制签名链接（1 小时）」 | 为单个对象生成签名 GET URL 并复制，提示「已复制「key」的签名链接」 |
| 工具栏 →「复制链接」 | 为所有选中文件批量生成（内部 4 路并发，逐行一个 URL），提示「已复制 N 个签名链接（1 小时有效）」 |
| 上传面板 →「完成」条目的「复制链接」 | 同上，用于「传完即分享」 |

- 服务端签名 URL 的默认有效期是 **1 小时**；请求可指定 `expiresIn`，超过 **24 小时会被钳到 24 小时**。
- 批量生成时个别失败不会中断其余项，失败对象会以「以下对象复制签名链接失败：…」提示。

### 预览

双击文件行、按 **Enter**（选中文件后）或点行内「预览」打开预览；**未知类型**双击会直接改为下载。

| 类型 | 扩展名（按扩展名判断） | 渲染方式 |
|---|---|---|
| 图片 | `png` `jpg/jpeg` `gif` `webp` `svg` `bmp` `avif` `heic` `ico` | 图片元素（`<img>` 上下文不执行脚本） |
| 视频 | `mp4` `webm` `ogv` `mov` `m4v` `mkv` `avi` | 原生播放器（支持拖动进度，服务端透传 Range） |
| 音频 | `mp3` `wav` `ogg` `oga` `m4a` `flac` `aac` `opus` | 原生播放器 |
| PDF | `pdf` | 沙箱 iframe（禁用脚本与弹窗） |
| 文本 / 代码 | `txt` `md` `json` `csv` `log` `yaml` `xml` `html` `css` `js` `ts` `go` `py` `java` `sql` `sh` `vue` 等 | 纯文本转义展示（**HTML / SVG 源码只按文本显示，绝不渲染**） |
| 其他 | — | 「该格式暂不支持预览，请下载查看。」 |

- 文本预览只取**前 1MB**，超出时显示「⚠ 文件较大，仅显示前 1MB（请下载查看完整内容）」。
- 预览弹窗右上角有「下载」「关闭」，**Esc** 关闭。

### ZIP 打包下载

1. 勾选一个或多个文件，点工具栏「ZIP 下载」（按钮在打包期间显示「打包中…」）。
2. 服务端**流式打包**（不在服务端落盘）；浏览器支持「另存为」时直接流式写入所选文件，否则退化为内存 blob 下载。
3. 成功提示「已打包 N 个对象为 ZIP」；默认文件名为 `objects-YYYY-MM-DD-HH-MM-SS.zip`。

> **部分失败语义**：某个对象取回失败时，ZIP 仍会生成并下载，失败对象会记录在压缩包内的 **`_下载失败清单.txt`** 中（服务端同时记录告警日志与指标），界面不会把它当作整体失败。
> **体积兜底**：当浏览器不支持流式保存、且响应 `Content-Length > 500MB`（或长度未知而所选文件超过 50 个）时会拒绝并提示「ZIP 过大，当前浏览器不支持流式保存。请改用支持“另存为”的浏览器，或减少所选文件数量后再试。」

## 六、对象操作

| 操作 | 入口 | 行为与注意 |
|---|---|---|
| 新建文件夹 | 工具栏「+ 新建文件夹」 | 输入名称（例如 `images`），服务端写入以 `/` 结尾的空对象；名称不能为空 |
| 重命名 / 移动 | 右键「重命名」或 **F2** | 弹窗「重命名 / 移动」，输入**新 Key**（可含路径，如 `dir/name.txt` 即移动到 `dir` 下）；服务端**先复制后删除**，复制失败不会丢源；同桶内新旧 key 相同会被拒绝 |
| 复制到… | 右键 / 工具栏 | 统一对话框：选**目标 Bucket**（可跨桶）+ 目标路径；复制**不删除源** |
| 移动到… | 右键 / 工具栏 | 同上，但**复制成功后才删除源** |
| 删除（单个） | 右键「删除」 | 确认框「确定删除对象「key」？该操作不可恢复。」 |
| 删除（批量） | 工具栏「删除」 | 确认框「确定删除选中的 N 个对象？…」；前端按 **1000 个一批串行提交**，单片失败不中止其余分片 |
| 删除文件夹 | 右键「删除文件夹（含全部内容）」 | 递归删除该前缀下全部对象；确认后走**异步任务 + 进度提示**（「删除中 done/total…」），完成后提示「已删除 N 个对象」 |
| 批量改元数据 | 工具栏「批量改元数据」 | 对选中对象统一修改 ACL / 标签 / 存储类型，**4 路并发**，显示进度与失败明细 |
| 权限设置（ACL） | 右键「权限设置」/ 详情 | 切换 `私有（仅账号可访问）` ↔ `公共读（所有人可读）`；展示所有者、授权列表与公开链接，可「复制公开链接」 |
| 编辑标签 | 右键「编辑标签」/ 详情 | 键值行编辑（+ 添加 / ✕ 删除），保存时**覆盖**写入；空 key 的行不会提交，全部为空即清空标签 |
| 存储类型 | 详情中的「切换」 | 见下表 |
| 编辑 HTTP 头 | 详情中的「编辑 HTTP 头」 | 设置 Content-Type 与自定义元数据；Content-Type 留空表示不修改，自定义元数据为**整体覆盖**（清空所有行即清空元数据） |

### 复制 / 移动的细则

| 场景 | 行为 |
|---|---|
| 单个文件 | 目标路径可含目录；目标与前缀组合成新 key |
| 文件夹 | 整个前缀（含子目录）递归复制；同桶内目标前缀不得与源前缀重叠（服务端拒绝，防无限复制） |
| 批量（多选） | 批量复制 / 移动所选文件到目标前缀，**保留文件名**；移动 = 复制成功后删源 |
| 大任务 | 文件夹与批量操作走异步任务 + 进度提示；源对象数超过服务端列举上限时会提示「已复制 N 个对象（源对象数超过列举上限，仅复制一部分）」 |
| 部分失败 | 提示「已复制 N 个对象，失败 M 个」；移动时若有失败则**保留源文件夹**（提示「复制完成但有 M 个失败，已保留源文件夹」） |

### 存储类型（StorageClass）

可选值（下拉中的中文标签）：

| 值 | 显示 |
|---|---|
| `STANDARD` | 标准 (STANDARD) |
| `STANDARD_IA` | 低频访问 (STANDARD_IA) |
| `ONEZONE_IA` | 单区低频 (ONEZONE_IA) |
| `INTELLIGENT_TIERING` | 智能分层 (INTELLIGENT_TIERING) |
| `GLACIER_IR` | 瞬时归档 (GLACIER_IR) |
| `GLACIER` | 归档 (GLACIER) |
| `DEEP_ARCHIVE` | 深度归档 (DEEP_ARCHIVE) |
| `REDUCED_REDUNDANCY` | 低冗余 (REDUCED_REDUNDANCY) |
| `EXPRESS_ONEZONE` | 单区高速 (EXPRESS_ONEZONE) |

- 切换通过**服务端复制对象到自身**实现；版本控制桶会写出一条**新版本**。
- `GLACIER` / `DEEP_ARCHIVE` 等归档类型需先恢复（restore）才能读取。
- 选择与当前类型相同时会提示「存储类型未变化」并不提交。

### 批量改元数据

1. 勾选若干对象 → 工具栏「批量改元数据」。
2. 弹窗顶部提示「对当前选中的 N 个对象，统一修改 ACL / 标签 / 存储类型（4 路并发）。」
3. 按需勾选要修改的项：
   - **ACL**：`private` / `public-read` / `public-read-write`；
   - **标签**：`（不修改）` / `替换` / `清空全部标签`；选「替换」时每行都必须填写标签键；
   - **存储类型**：直接填写目标值。
4. 点「应用」执行；执行中显示「执行中 done/total」，结束显示「成功 ok，失败 failed」。
5. 失败明细默认展示前 50 条（`key · 步骤 · 消息`），超过时可「显示全部 N 条」/「收起」。

> 约束：至少勾选一项修改，否则提示「请至少勾选一项修改（ACL / 标签 / 存储类型）」；单次最多 **10000** 个 key（超出会直接报错，请分批）。

## 七、版本与回收站

### 开启版本控制

1. 进入「桶管理」→ 选中桶 → **概览** 页签，或「对象管理」工具栏的「桶属性」按钮。
2. 在「版本控制」一行点「开启」，确认后提示「已开启版本控制」。
3. 需要停止时点「暂停」（已存在的历史版本仍会保留）。

> 版本控制开启后，对象的**覆盖写入与删除都会保留历史版本**，可在对象详情的「版本」里查看 / 还原。

### 历史版本列表

右键文件 →「版本」（或详情里的「版本」）打开「版本 · key」弹窗：

| 列 | 说明 |
|---|---|
| 类型 | `最新` / `历史` / `删除标记` |
| VersionId | 版本号（无版本号时显示 `null`） |
| 修改时间 / 大小 / 存储类型 | 该版本的元数据（删除标记的大小显示 `—`） |
| 操作 | 内容版本：`恢复` / `删除`；删除标记：`还原` / `删除标记` |

- 列表按修改时间**倒序**（最新在前）。
- 单次加载最多翻 **20 页**（每页最多 1000 条）；仍被截断时显示红色提示「⚠ 版本过多，仅显示前 P 页（每页最多 1000 条）；完整列表请用 API/S3 客户端查看。」
- 若包含删除标记，会显示徽标「含删除标记（可一键还原已删除对象）」。

| 操作 | 确认文案与结果 |
|---|---|
| 恢复某版本 | 「确定将「key」恢复为版本 V 吗？这会在当前 key 写出一条新的当前版本（内容为该版本）。」→ 提示「已恢复「key」为版本 V」 |
| 删除指定版本 | 「确定删除「key」的版本 V 吗？该版本将被永久删除，不可恢复。」 |
| 还原删除标记 | 「确定还原已删除的「key」吗？这会把删除标记从对象上移除，使对象回到删除前的状态。」 |

### 版本比较

1. 在版本弹窗点「比较两个版本」（需要 **≥2 个内容版本**，删除标记不参与比较）。
2. 选择**基准版本**与**目标版本**，点「比较」。
3. 可比较时展示逐行差异，并可「下载基准版本 / 下载目标版本」。

| 情况 | 表现 |
|---|---|
| 任一侧 > 2MB | 「版本较大（>2MB），为避免卡顿仅展示元数据对比。」 |
| 内容为二进制 | 「内容为二进制，无法做文本差异；可分别下载查看。」 |
| 拉取失败 | 「内容拉取失败：…（可能是 S3 未配置 CORS 或对象不可读，可改用下载查看）。」 |

### 回收站

「回收站」菜单列出桶内**所有已删除对象（删除标记）**：

1. 顶部选择**账号**与**桶**（无账号 / 无桶时给出引导文案）。
2. 列表列：对象（Key）、VersionId、删除时间、操作；底部显示「已显示 N 项」。
3. 点「还原」→ 确认「确定还原「key」吗？这会移除该删除标记，使对象回到被删除前的状态。」→ 提示「已还原「key」」。
4. 点「彻底清除」→ 确认「确定彻底清除「key」吗？该对象的所有版本与删除标记将被永久删除，无法再还原。」→ 提示「已彻底清除「key」（删除 N 个版本）」。
5. 数据多时点「加载更多」继续翻页；徽标显示「还有更多删除标记」/「已到末尾」。

> 空态提示：「回收站为空。版本控制开启时，删除的对象会进入这里。」

## 八、桶管理菜单

「桶管理」菜单 = 桶列表 + 每个桶的设置页签。

### 桶列表

- 顶部选择账号，右上角「+ 新建桶」；表格列为「桶名 / 创建时间 / 操作」，操作为「管理」「删除」。
- 「删除」会提示「确定删除桶「名称」？桶必须为空才能删除。」。

### 设置页签（选中桶后）

页签依次为：**概览 / 生命周期 / 加密 / CORS / 网站托管 / 桶策略 / 标签**。

| 页签 | 可做的事 | 关键提示 |
|---|---|---|
| 概览 | 查看桶名、区域、创建时间、版本控制状态；「开启」/「暂停」版本控制 | 「版本控制开启后，对象的覆盖写入与删除都会保留历史版本，可在对象详情的「版本」里查看/还原。」 |
| 生命周期 | 编辑前缀过期删除规则：规则 ID（自动生成，只读展示）、前缀、过期天数；「+ 新增规则」「保存规则」 | 「生命周期规则用于按前缀自动过期删除对象。」；「⚠ 基于 S3 兼容生命周期 API（MinIO / AWS 支持；部分厂商兼容性有限）。」保存后提示「已保存 N 条生命周期规则」 |
| 加密 | 默认加密算法：`SSE-S3 (AES256)` / `SSE-KMS (aws:kms)` / `SSE-KMS 双加密 (aws:kms:dsse)`；选 KMS 时可填「KMS 主密钥 ID」；「启用桶密钥（bucket key）」；「保存」/「关闭加密」 | 「默认加密会对新写入对象自动加密；已存在对象不受影响。」 |
| CORS | 每条规则可设：规则 ID、允许的方法（GET/PUT/POST/DELETE/HEAD 勾选）、允许的来源（逗号分隔）、允许的头（逗号分隔）、暴露的头（逗号分隔）、缓存秒数；「+ 添加规则」「保存」「清空全部」 | 保存后提示「已保存 CORS 规则」/「已清空 CORS 规则」 |
| 网站托管 | 索引文档（如 `index.html`）、错误文档（可选）、全量重定向主机（可选）；「保存」/「关闭网站托管」 | 「至少填写「索引文档」或「全量重定向主机」其一」；端点形如 `{bucket}.s3-website-{region}.amazonaws.com`（各厂商略有差异） |
| 桶策略 | 「可视化编辑」与「原始 JSON」双模式；4 个模板：`公共读（GetObject）` / `公共读写` / `拒绝 List` / `清空`；Statement 表单（Effect / Principal / Action / Resource / Sid）；「+ 新增 Statement」「JSON 预览」；「保存」/「移除策略」 | 有未保存修改时显示「有未保存的修改」；JSON 不合法或含可视化不支持的结构时切到原始 JSON 并提示原因 |
| 标签 | 键值表，「+ 添加标签」「保存」「清空全部」 | 保存后提示「已保存桶标签」/「已清空桶标签」 |

> 桶策略的校验会在保存前提示：`Version 必须为 "2012-10-17"`、`Statement 必须为数组`、`第 N 条 Effect 非法`、`第 N 条 Principal 不能为空（用 * 表示所有人）`、`第 N 条 Action 不能为空`、`第 N 条 Resource 不能为空`、`Sid "x" 重复（S3 桶策略 Sid 必须唯一）`。

> 「对象管理」工具栏的「桶属性」弹窗与这里是同一份数据（区域 / 创建时间 / 版本控制），便于在浏览对象时就地开关。

## 九、迁移与增量同步

### 迁移（跨账号 / 跨桶复制）

1. 打开「文件迁移」菜单；顶部显示「源账号：当前账号名」。
2. 选择**源 Bucket**（下拉第一项为账号默认桶）与**源前缀**（例如 `dir/`，可不填）。
3. 点「列出对象」只列当前层文件（每页 200 条）；点「列出全部文件」则**递归收集包含子目录的全部文件**：
   - 每页 1000 条，**最多 200 页（约 20 万个对象）**；
   - 成功提示「已列出 N 个文件（含子目录）」，达到上限提示「对象较多，已收集前 N 个文件（超出上限）」。
4. 勾选要迁移的文件，或用「全选」。
5. 选择**目标账号**（列表里同账号会标注「（同账号）」；默认优先选另一个账号）、**目标 Bucket**、**目标前缀（增加前缀）**（例如 `archive/`）。
6. 点「开始迁移」。
7. 迁移过程：按钮变为「迁移中 done/total」，并有进度条；可点「取消迁移」（提示「已请求取消迁移」，完成后提示「迁移已取消：成功 ok，失败 fail」）。
8. 结束后弹出「迁移结果」：成功 N / 失败 N / 共 N 个对象，失败时展示**失败对象清单（最多 200 个）**与「首个错误」，可点「去目标账号查看」跳转到目标账号的对象管理。

| 场景 | 复制方式 |
|---|---|
| 源与目标 **endpoint 相同** | 服务端 `CopyObject`（数据不经过浏览器） |
| 源与目标 **endpoint 不同** | `GetObject` → `PutObject` 流式转发，保留 Content-Type 与元数据 |
| 单次提交规模 | 单个请求最多 **10000 个 key**，超出会**自动分片串行提交**（进度按分片累加，不倒退） |
| 失败处理 | 逐 key 继续执行、失败不中断；失败清单上限 200 条（`failed` 计数不受裁剪影响） |
| 超大对象 | 跨 endpoint 流式复制单对象上限为 640GB（64MB × 10000 段），超限会被明确拒绝并中止，不会静默截断 |

### 未完成任务（服务重启后的对账）

如果服务在迁移过程中重启，被中断的任务会显示在面板顶部的「未完成任务」区块：

- 标签为 `已中断` 或 `进行中`，并显示「中断于 done/total」；
- 提示「服务重启导致以下任务中断。移动任务可能「已复制但源未删除」，请核对后手动处理。」；
- 点「忽略」只从当前列表移除（服务端记录仍按 TTL 保留，供审计），点「刷新」重新读取。

### 增量同步（仅 API）

> ⚠ **当前版本的界面没有增量同步入口。** 增量同步只有服务端接口 `POST /api/migrate/sync`，需要用脚本 / curl 调用；请求字段、比对模式（`etag`（默认）/ `size_mtime` / `always`）、响应字段（`scanned` / `skipped` / `copied` / `failed` / `failedKeys` / `truncated`）与「源侧列举命中 10 万硬上限时 `truncated=true`、需再次执行继续同步」的注意事项，见 [`api.md`](api.md) 的「增量同步」一节。

## 十、桌面端

桌面端是 **Tauri 2 打包的同一个前端**：不使用 Tauri IPC，所有请求都通过 HTTP 访问后端，因此**必须先有一个可用的后端**（本机或远程）。

> 桌面端（Windows / macOS / Linux）与 Web 端浏览器的**支持矩阵**（含「✅ 已实现 / ⚠️ 部分 / ❓ 未验证」与依据）见 [compatibility.md](compatibility.md#62-客户端支持矩阵浏览器与操作系统)。

### 首次启动配置

1. 启动桌面应用（窗口标题 `S3 Client`，默认 1200×800，最小 900×600）。
2. 打开左侧「配置」→**服务器设置**：首次启动会自动生成一个名为「本机后端」的服务端条目，地址为 `http://127.0.0.1:8080`。
3. 若后端不在本机，点「编辑」把「后端地址」改成实际地址并保存（保存当前生效项后界面会自动刷新）。
4. 后端启用了鉴权时填写「鉴权 Token」（即 `S3C_TOKEN`）；Token 支持逗号分隔的多个值，客户端原样保存；**服务端吊销需改环境变量并重启**。
5. 点「检测」或「全部检测」确认连通（正常时会显示后端版本号）。

### 与 Web 端的差异

| 维度 | Web 端 | 桌面端 |
|---|---|---|
| 打开方式 | 浏览器访问后端地址（默认同源） | 独立窗口，无地址栏 |
| 默认后端地址 | 空 = 同源 | `http://127.0.0.1:8080`（本机后端） |
| 默认服务端条目名称 | 「同源（默认）」 | 「本机后端」 |
| Token 存储 | 默认 sessionStorage（关标签即清）；勾选「跨会话保留」才写 localStorage | 同左 |
| 功能范围 | 完全一致（同一套前端代码、同一套 HTTP 接口） | 同左 |
| 分发产物 | 由你自己的 Web 服务器 / Docker 提供 | `.exe`（NSIS）/ `.deb` / `.dmg`，随 GitHub Release 发布并附 `SHA256SUMS` |

> 桌面端产物目前**未做代码签名 / 公证**（依赖外部证书，见 [`KNOWN_ISSUES.md`](KNOWN_ISSUES.md) §一 #25），首次运行可能被 Windows SmartScreen / macOS Gatekeeper 拦截，需要手动放行；校验方式见 [`DEPLOYMENT.md`](DEPLOYMENT.md)。

## 十二、常见问题

| 问题 | 说明 |
|---|---|
| AccessKey Secret 会保存在浏览器里吗？ | 不会。Secret 只在你点保存时提交给服务端；服务端存储它，且**任何接口都不回传**（只返回「是否已设置」）。编辑账号时留空即表示不修改。 |
| 「下载」为什么不是签名 URL？ | 下载走**服务端代理**（强制附件 + 携带鉴权），这样在启用 `S3C_TOKEN` 时也能用，且错误响应不会被当成文件保存。要「分享给别人」请用右键「复制签名链接（1 小时）」。 |
| 分享链接多久失效？ | 界面生成的分享链接为 **1 小时**；接口默认也是 1 小时，最长可到 24 小时（超过会被钳制）。 |
| 为什么上传失败提示「未读取到 ETag」？ | 分段上传需要读取每段的 `ETag` 响应头，请给桶配置 CORS 并**暴露 `ETag`**。 |
| 复制了「公开链接」却打不开？ | 该对象必须先是**公共读**（权限设置里切换），链接才可匿名访问；ACL 弹窗有对应提示。 |
| 删除对象后为什么还能找回来？ | 桶开启版本控制后，普通删除只会写一条**删除标记**，对象数据仍在。可在「回收站」还原，或在对象的「版本」里还原删除标记。 |
| 「彻底清除」和「删除」有什么区别？ | 「彻底清除」会删除该 key 的**全部版本与删除标记**，不可再还原；「删除」在版本控制桶里只新增删除标记。 |
| 桶删不掉？ | 桶必须为空。非空时服务端返回 `bucket not empty`，请先删除桶内对象（含历史版本）。 |
| 列表为什么只有 100 条？ | 分页设计。「加载更多」每次追加 100 条；「加载全部」最多约 2 万条（200 页），超过会给出截断提示。 |
| 过滤 / 排序为什么不影响未显示的对象？ | 过滤与排序都在本地对**已加载**条目生效；未加载的部分需要先「加载更多 / 加载全部」。 |
| 开启版本控制之前的版本能看到吗？ | 不能。只有开启版本控制之后发生的覆盖 / 删除才会保留历史版本。 |
| 切到「归档」存储类型后读不到内容？ | `GLACIER` / `DEEP_ARCHIVE` 等归档类型需要先恢复（restore）才能读取，这是 S3 语义。 |
| 增量同步在哪里？ | 当前界面没有入口，只能用接口 `POST /api/migrate/sync`，见 [`api.md`](api.md)。 |
| 内网 / 本机 MinIO 连不上？ | 默认允许私网与回环地址；若服务端开启了 `S3C_SSRF_DENY_PRIVATE`，内网 Endpoint 会被拒绝，需要部署方调整，见 [`CONFIGURATION.md`](CONFIGURATION.md)。 |
| 「账号」和「服务器设置」有什么区别？ | 「账号」是**你的 S3 凭据**（AK/SK/Endpoint）；「服务器设置」是**这个控制台后端**的地址与 Token。两者互不相干。 |
| 对象数据存在哪里？ | 一直在你的 S3 服务上。本控制台只在服务端保存账号配置（凭据可加密落盘），不保存对象内容。 |
| 界面语言和主题怎么换？ | 顶栏右侧按钮：语言在 `中文` / `EN` 间切换；主题按钮点击在 `跟随系统` → `浅色` → `深色` 间循环。 |

## 十三、排障

> 本节的读者是**使用者**，只覆盖「你在界面上看到的现象」。与运维资料的边界：
>
> - 服务端的健康端点 / 指标 / 日志 / 故障处置 Runbook / 备份与恢复 / 容量与灾难恢复 → **运维手册 [`OPERATIONS.md`](OPERATIONS.md)**；
> - 部署形态、compose、Nginx、TLS → [`DEPLOYMENT.md`](DEPLOYMENT.md)；
> - 环境变量取值与约束 → [`CONFIGURATION.md`](CONFIGURATION.md)；
> - 错误码到 HTTP 状态与文案的完整映射 → [`errors.md`](errors.md)。

| 现象 | 自查 | 处理 |
|---|---|---|
| 顶栏显示「连接异常」，横幅「无法连接后端」 | 后端是否已启动？「服务器设置」里的后端地址 / Token 是否正确？ | 点横幅「去配置」修正地址与 Token；后端恢复后系统每 5 秒自动重试并重新加载，无需刷新页面 |
| 账号列表点「测试」显示 `失败` | 鼠标悬停 `失败` 看具体原因；核对 Endpoint / Region / AK / SK / Path-style / HTTPS | 按原因修正：`invalid credentials` → 换 AK/SK；`bucket not found` → 核对默认桶或权限；内网地址被拒 → 见 [`CONFIGURATION.md`](CONFIGURATION.md) 的 `S3C_SSRF_DENY_PRIVATE` |
| 有桶但在界面上看不到 | 当前选中的账号是否正确？该 AK 是否有 `ListBuckets` 权限？ | 在「对象管理」顶部或「桶管理」切换账号；权限不足需在 S3 侧授权（错误文案见 [`errors.md`](errors.md)） |
| 列表报错后一直显示红色横幅 | 是否只是瞬时抖动？ | 横幅提供「重试」与「关闭」两个按钮；「重试」会重新拉取桶列表与当前目录 |
| 上传失败：`分段上传失败：HTTP xxx` | 桶的 CORS 是否允许该来源与 `PUT`？凭据是否对目标桶可写？ | 配置桶 CORS（并暴露 `ETag`）；在「桶管理 → CORS」里维护规则 |
| 上传失败：`分段上传网络错误` | 网络是否中断？直传地址（公网 Endpoint）是否可达？ | 检查网络与「公网 Endpoint」配置；失败条目可在「文件上传」页用「重试失败」重跑 |
| 上传失败：`分段上传完成但未读取到 ETag` | 桶 CORS 是否暴露 `ETag` 响应头？ | 到「桶管理 → CORS」把 `ETag` 加入「暴露的头」 |
| 单次上传提示对象过大 | 文件是否超过 5GB 且未走分段？ | < 100MB 走单次 PUT、≥ 100MB 自动分段；若单对象极大请注意浏览器与服务端限制 |
| 预览空白 / 图片打不开 | 该对象是否可读？网络是否可达 S3？ | 点「下载」验证对象本身可读；预览失败会给出原因文案 |
| 版本比较报「内容拉取失败」 | 提示里已说明可能是 S3 未配置 CORS 或对象不可读 | 改用「下载基准 / 目标版本」比对；或在 S3 侧放开 CORS |
| 批量删除提示部分失败 | 失败原因在提示里（`access denied` 等） | 检查桶策略 / 保留期 / MFA Delete 等拒绝条件；被拒对象在 S3 侧处理 |
| 删除文件夹提示「已删除 N 个对象（超出上限，仅删除部分）」 | 前缀下对象数超过服务端上限（10 万个） | 分批删除（按子前缀分别删除） |
| 迁移结果里出现失败清单 | 「首个错误」告知原因，清单最多 200 条 | 按 key 重试迁移；权限 / 网络类问题先在 S3 侧解决 |
| 迁移面板顶部出现「未完成任务」 | 任务被服务重启中断 | 提示明确要求对账：**移动任务可能「已复制但源未删除」**，请人工核对源与目标后再「忽略」 |
| ZIP 下载被拒绝 | 浏览器不支持流式保存，且响应超过 500MB 或长度未知而文件数 > 50 | 换用支持「另存为」的浏览器，或分批下载 |
| 快捷键无反应 | 焦点是否在输入框 / 下拉框 / 按钮上？是否在对象管理面板且已进入某个桶？ | 点击列表空白处让焦点回到页面后再试；各键的生效范围见 [十一、快捷键](#十一快捷键) |
| 界面文案 / 主题 / 语言被改乱 | 本地存储中保存了语言（`s3c.locale`）、主题（`s3c.theme`）、提示条开关（`s3c.hintsHidden`）等偏好 | 用顶栏按钮切回；如需彻底重置可清除该站点的浏览器本地存储（会同时清掉「跨会话保留」的 Token 与本机记忆的账号选择） |

## 十四、数据与隐私

> 本节只写**可从代码核实**的事实（文件 / 变量 / 行为均已逐条复核）。凡是本仓库没有实现的
> 东西（账号体系、云同步、遥测）就不写——**不存在的能力不做承诺**。

**不发送遥测。** 本工具没有埋点、崩溃上报或使用统计：全仓生产代码检索 `sentry` / `posthog` /
`analytics` / `telemetry` / `mixpanel` / `amplitude` / `gtag` 等标识符**零命中**；前端生产
`dependencies` 只有 `vue`，桌面端 `dependencies` 为空。网络请求只有两类去向——你自己配置的
**后端地址**（`/api/*`）与**你的 S3 端点**（含预签名直传 / 预览）：见 `api/http.ts`、
`proxy.ts`、`jobs.ts` 的 `fetch` 调用点。

**凭据存在哪里。**

| 凭据 | 存放位置 | 说明 |
|---|---|---|
| 账号 `secretKey`（S3 密钥） | **仅服务端**：`S3C_DATA_DIR` 下的 `accounts.json` / `accounts.db` / `accounts.json.enc` | API 响应里**不含** `secretKey`：账号对外视图用 `secretSet` 布尔表示「是否已设置」。浏览器端**从不**保存 `secretKey` |
| `S3C_STORE_KEY`（账号库加密密钥） | 只在你部署处的环境变量 / 密钥管理里 | 非空时账号库加密落盘（`encrypted` 驱动整文件加密；`json` / `sqlite` 时密钥字段加密）。**它丢了，账号库就解不开**——务必与备份分开保管 |
| `S3C_TOKEN`（后端访问令牌，前端填写） | 浏览器：默认 **`sessionStorage`**（关标签即失效）；勾选「跨会话保留」后才写 `localStorage` | 若该部署不设 `S3C_TOKEN`，则不需要填写 |

**日志不含密钥。** 服务端日志记录的是请求 ID / 路径 / 桶 / 错误原因等（如 `audit` 事件、
`handler error`），不打印 `secretKey`、访问密钥或令牌原文；可自行复核：对
`apps/server/**/*.go` 同时匹配 `secret` / `token` 与 `log` 只命中函数**签名**里的参数名，
**没有**任何一条日志调用带密钥字段。

**浏览器本地存储里到底有什么**（清站点数据会一并清掉）：语言 / 主题 / 提示条偏好、记忆的
账号选择、后端地址与「跨会话保留」开关。**唯一可能带凭据的是上面的 `S3C_TOKEN`**，且默认只
在会话内有效。多人在共用电脑上使用时，请保持「跨会话保留」为**关闭**，用完关标签页。
