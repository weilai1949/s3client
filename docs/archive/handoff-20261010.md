- **改了什么**：`components.responses` 的 `Unauthorized` / `TooManyRequests` / `InternalError`
  此前**定义后 0 引用**、84 个 operation 无一声明 `401/413/429/500`。现新增
  `internal/openapi.ForEachOperation` 遍历器 + `handler.applyUniversalResponses`（`registerOpenAPI`
  末尾统一补挂：`429/500` 全端点、`401` 除 `security: []` 的 health / metrics、`413` 仅带请求体端点，
  已显式声明的不覆盖）+ 新共享组件 `PayloadTooLarge`；`info.description` 的「JSON 例外」措辞订正。
- **为什么集中补挂而不是逐条写**：84×4 处手写必然漂移；补挂点单一、由门禁钉住。
- **门禁**：`TestOpenAPIUniversalResponsesAreWiredPerOperation`（先红后绿）；黄金文件经
  `-update-openapi-spec` 重生成（`docs/api/openapi.json` +891 行），前端 `pnpm gen:api`
  同步（`schema.d.ts` +302 行，`operations.ts` 无变化）。
